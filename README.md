# SpilnoDoc — вебсервіс для спільного редагування документів

Курсова робота з ОК «Вебпрограмування».
Автор: Подзюбанчук Тимур Артемович, група ІПЗ-41.

Кілька користувачів редагують один документ одночасно і бачать зміни
один одного в реальному часі. Конфлікти паралельних правок розв'язуються
алгоритмом операційного перетворення (Operational Transformation).

## Можливості
- реєстрація та вхід (JWT, паролі хешуються scrypt);
- створення, перейменування, видалення документів;
- надання доступу іншим користувачам із ролями «редактор» і «читач»;
- спільне редагування в реальному часі (Server-Sent Events + OT);
- список співавторів онлайн із позицією їхнього курсора;
- історія версій: ручні та автоматичні знімки, перегляд, відновлення;
- розмітка Markdown із попереднім переглядом, експорт у .md.

## Вимоги
Node.js 22.13 або новіший (використовується вбудований модуль `node:sqlite`).

## Запуск
Клієнтська частина вже зібрана в каталозі `public/`, тому серверу
не потрібні жодні npm-пакети:

```
npm start
```

Після запуску відкрийте http://localhost:3000.
Щоб перевірити спільне редагування, увійдіть під двома різними
користувачами у двох вікнах (наприклад, звичайному та приватному).

## Розробка клієнта
```
npm install      # React, esbuild, marked, DOMPurify
npm run build    # збирання клієнта в public/assets
npm run dev      # автоматичне перезбирання під час змін
```

## Тести
```
npm test
```

## Змінні середовища
| Змінна | Призначення | За замовчуванням |
|---|---|---|
| PORT | порт HTTP-сервера | 3000 |
| JWT_SECRET | секрет підпису токенів | генерується в data/.jwt-secret |
| DATA_DIR | каталог бази даних | data/ |
| AUTH_RATE_LIMIT | спроб входу за 15 хвилин з однієї IP | 10 |
